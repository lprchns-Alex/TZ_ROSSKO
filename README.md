# Курьер на выбор

Решение тестового задания для ROSSKO: оформление заказа в интернет-магазине автозапчастей, где клиент выбирает курьера — красивого или умного.

**Документ:** https://lprchns-alex.github.io/TZ_ROSSKO/

**Кликабельный прототип:** https://lprchns-alex.github.io/TZ_ROSSKO/prototype/

## Что внутри

- `index.html` — документ: аналитика, концепция, флоу по экранам, крайние случаи, метрики.
- `Флоу оформления заказа.md` — тот же материал в виде рабочих заметок.
- `prototype/index.html` — кликабельный мобильный прототип оформления заказа в стиле ROSSKO Розница. Справа панель сценариев (бизнес-аккаунт, переходы по экранам). Логотип — из сохранённой страницы rossko.ru, только для тестового.

## Задание

> Мы запускаем интернет-магазин с WOW-функцией — при оформлении заказа можно выбрать, какой курьер его доставит: красивый или умный. Предварительное закрытое тестирование показало, что потенциальные клиенты чаще выбирают красивых, но бизнесу интереснее отправлять умных. Надо тщательно продумать решение и задизайнить процесс оформления заказа.

Компания, ситуация и персонажи вымышлены по условиям задания.
